# 앱 소개: 새 회원에게 모든 기능을 한 장씩 보여 주기

회원가입하고 처음 들어온 사람에게 앱의 모든 기능을 한 장씩 넘겨 보는 소개 창이 뜬다. 짧은 사용 설명서 같은 역할이고, 파스텔 글래스 테마에 맞춘 유리 창으로 보인다. 소개는 `features/onboarding/steps.ts` 한 파일의 목록으로 만들어서, 기능이 바뀌면 그 목록의 문구만 고치면 된다.

연결된 근거:
- [PRODUCT.md](../../../PRODUCT.md) — "처음 가 보는 길에서도 어려움 없이", "무겁지 않게, 필요한 순간에 필요한 것만", "말투와 경험을 2030에 맞춘다".
- [visual-theme](../../decisions/visual-theme.md) — 소개 창도 반투명 유리 면, 알약 버튼, 한글 산세리프를 쓰고 글자 대비 4.5:1을 지킨다.
- [ui-composition](../../decisions/ui-composition.md) — 버튼과 배지는 공식 구성을 쓴다. 이 앱에는 대화 상자 부품이 없어서 접근성 속성(`role="dialog"`)을 직접 붙인 창을 쓴다.
- [data-storage](../../decisions/data-storage.md) — 소개를 봤는지는 계정에 묶어 저장한다.
- [GLOSSARY.md](../../../GLOSSARY.md) — 앱 소개의 뜻.

## 사용자에게 보이는 결과

1. 처음 로그인한 계정이 내 여행, 여행, 여행 만들기 화면을 열면 소개 창이 화면 위에 뜬다.
2. 창에는 한 번에 한 장이 보이고, 아이콘, 제목, 두세 줄 설명, 핵심 세 줄이 있다. 위에 "2 / 7" 같은 진행 표시, 아래에 단계 점이 있다.
3. "다음", "이전", "건너뛰기"로 넘기고, 마지막 장의 "시작하기"로 닫는다. 키보드의 좌우 화살표와 Esc도 된다.
4. 한 번 닫으면(끝까지 봤든 건너뛰었든) 다시 자동으로 뜨지 않는다. 다른 기기에서 로그인해도 같다.
5. 내 여행 화면 아래의 "앱 소개 보기"로 언제든 다시 볼 수 있다.

## 승인된 범위

- 소개 창과 일곱 장의 내용(환영, 코스, 출발 전 준비, 환율·여비, 필요한 순간의 제안, 함께 가기, 시작)
- 계정에 소개를 봤다고 기록하기, 내 여행 화면의 다시 보기 버튼
- 기능이 바뀔 때 소개 문구를 함께 고치는 규칙(`AGENTS.md`)

## 수용 기준

실행 중인 앱에서 실제 브라우저로 확인한다.

- AC1. 새로 가입한 계정으로 처음 로그인해 내 여행, 여행, 여행 만들기 중 어느 화면을 열어도 소개 창이 뜨고, 첫 장은 환영 장이다.
- AC2. "다음"을 누르면 다음 장, "이전"은 앞 장으로 가고, 첫 장에는 "이전"이 없다. 단계 점을 누르면 그 장으로 간다. 좌우 화살표 키도 같다.
- AC3. 마지막 장에는 "건너뛰기"가 없고 "시작하기"가 있다. "시작하기", "건너뛰기", 닫기(×), Esc 중 무엇으로 닫아도 창이 사라지고, 새로고침하거나 다시 로그인해도 다시 뜨지 않는다.
- AC4. 소개를 본 계정으로 다른 브라우저에서 로그인해도 뜨지 않는다. 이미 가입했던 계정도 첫 로그인 때 한 번 뜬다.
- AC5. 내 여행 화면의 "앱 소개 보기"를 누르면 같은 창이 다시 뜨고, 닫아도 다른 상태는 바뀌지 않는다.
- AC6. 창의 글자는 유리 면 위에서 대비 4.5:1 이상이고, 휴대폰 폭(390px)에서 창이 화면 안에 들어와 내용이 잘리지 않는다. 모션 줄이기 설정에서는 장이 넘어갈 때 움직임이 없다.
- AC7. 소개 창이 떠 있을 때 키보드 초점이 창 안의 버튼에 있다.

## 확정된 제약과 근거

- 모든 기능을 한 장씩 넘겨 보는 소개를 처음 로그인에 보여 준다(사용자 확정, 2026-11-19).
- 소개 문구는 한 파일의 목록에서 가져오고, 기능을 더하거나 바꿀 때 같은 변경에서 그 목록도 고친다. 새 기능을 자동으로 알아채서 문구를 만들지는 않는다(사용자 요청, 2026-11-19).

## 가정 (바꿀 수 있음)

- 소개를 봤는지는 계정의 사용자 정보(`user_metadata.onboarded`)에 저장한다. 별도의 테이블이 필요 없다.
- 이미 가입한 계정에게도 첫 로그인 때 한 번 보여 준다. 새 기능이 많이 늘었기 때문이다.
- 소개 창은 일곱 장이고 장마다 핵심 줄은 최대 세 개다.
- 기능 그림은 아이콘으로 대신하고, 화면 캡처는 쓰지 않는다. 화면이 바뀔 때마다 이미지를 고치지 않기 위해서다.
- 화면 시안은 만들지 않았다. 기존 유리 면과 버튼의 조합이기 때문이다.

## 범위 밖과 이유

- 기능별 안내 말풍선(화면 위에서 하나씩 가리키는 투어) — 화면마다 위치를 맞춰야 해서 이번에는 한 장씩 넘기는 창만 만든다.
- 기능을 더하면 소개를 자동으로 만들기 — 문구는 사람이 고른 말이 좋아서 목록을 직접 고친다.
- 소개를 본 횟수와 중간에 그만둔 장 측정 — 이번에는 기록하지 않는다.
- 다국어 — 한국어만 쓴다.

## 남은 위험

- 소개 문구가 기능 변경을 따라가지 못하면 사실과 달라진다. `AGENTS.md`의 규칙과 사양 확인으로 막는다.
- 사용자 정보를 바꾼 직후에는 기기마다 로그인 정보의 갱신이 늦어, 드물게 한 번 더 뜰 수 있다.
