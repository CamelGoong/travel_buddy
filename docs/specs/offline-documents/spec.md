# 오프라인 서류 열기: 인터넷이 약한 공항과 입장 게이트에서도 서류 꺼내기

서류 보관함의 파일을 기기에 미리 저장해 두어, 인터넷이 없거나 약해도 항공권과 입장권을 열 수 있다. 항공권, 입장권, 숙소 예약, 교통패스 칸의 파일은 기본으로 저장하고, 여권, 여행자 보험, 직접 만든 칸의 파일은 사용자가 켠 것만 저장한다. 로그아웃하면 기기에 저장된 서류가 모두 지워진다. [trip-documents](../trip-documents/spec.md)와 [data-storage](../../decisions/data-storage.md)가 "오프라인이 핵심 요구로 확정될 때" 다시 보기로 미룬 "오프라인에서 서류 열기"를 해소한다.

연결된 근거:
- [PRODUCT.md](../../../PRODUCT.md) — 제품 전제. 이 작업에는 "도착한 장소의 입장권 띄우기", "무겁지 않게, 필요한 순간에 필요한 것만"이 적용된다.
- [data-storage](../../decisions/data-storage.md) — 서류 파일은 비공개 버킷에 계정별로 저장하고 서명 링크로 연다. 이 작업은 그 위에 기기 저장을 더하고, 이 결정이 "오프라인이 핵심 요구로 확정될 때"로 남긴 재검토 조건을 해소한다.
- [trip-documents](../trip-documents/spec.md) — 항공권과 입장권 제안 섬이 파일을 열 때도 저장된 파일을 먼저 쓴다.
- [trip-companions](../trip-companions/spec.md) — 동반자에게 함께 보기로 나눈 파일도 같은 기준으로 저장한다.
- [suggestion-nudge](../../decisions/suggestion-nudge.md) — 제안 섬의 파일 열기 동작은 그대로다.
- [ui-composition](../../decisions/ui-composition.md) — 스위치, 상태 표시, 안내는 공식 shadcn 구성을 쓴다. 화면 작업은 `DESIGN.md`부터 읽는다.
- [GLOSSARY.md](../../../GLOSSARY.md) — 서류 보관함, 서류 칸, 서류 파일의 뜻. 이 작업이 오프라인 저장을 더한다.

## 사용자에게 보이는 결과

1. 항공권, 입장권, 숙소 예약, 교통패스 칸에 파일을 올리면(또는 동반자가 함께 보기를 켠 파일이 생기면) 인터넷이 될 때 그 파일이 기기에 저장되고, 파일 옆에 "오프라인 저장됨" 표시가 보인다.
2. 여권, 여행자 보험, 직접 만든 칸의 파일에는 "오프라인에서도 열기" 스위치가 있고 기본은 꺼져 있다. 켜면 기기에 저장되고, 끄면 기기에서 지워진다.
3. 인터넷이 없을 때 앱을 열면 저장된 서류를 모아 보는 "오프라인 서류" 화면이 열리고, 파일을 누르면 열린다.
4. 인터넷이 없는 상태에서 항공권·입장권 제안 섬을 펼쳐 파일을 눌러도 저장된 파일이 열린다.
5. 저장되지 않은 파일을 인터넷 없이 열려고 하면 "인터넷이 연결되면 열 수 있어요"가 보인다.
6. 로그아웃하면 기기에 저장된 서류가 모두 지워진다.

## 승인된 범위

- 칸 종류에 따른 기본 저장, 파일마다 켜고 끄는 스위치(여권, 보험, 직접 만든 칸)
- 저장 상태 표시와 저장·삭제 동기화
- 인터넷 없이 앱을 열었을 때의 "오프라인 서류" 화면
- 제안 섬에서 저장된 파일 열기
- 로그아웃 시 저장분 삭제

## 수용 기준

모두 실행 중인 앱에서 실제 브라우저로 확인한다. 오프라인은 브라우저의 네트워크 끊기(오프라인 모드)로 만든다. 서비스 워커는 보안 연결이나 `localhost`에서만 동작하므로 배포 주소에서도 한 번 확인한다.

- AC1. 항공권 칸에 PDF를 올린 뒤 잠시 기다리면(인터넷이 되는 상태) 파일 옆에 "오프라인 저장됨"이 보인다. 입장권, 숙소 예약, 교통패스 칸도 같다.
- AC2. 여권 칸에 올린 파일에는 "오프라인에서도 열기" 스위치가 있고 꺼져 있다. 켜면 "오프라인 저장됨"이 보이고, 끄면 사라지며 기기에서 지워진다. 여행자 보험과 직접 만든 칸도 같다.
- AC3. 네트워크를 끊은 상태에서 앱 주소를 열면 "오프라인 서류" 화면이 열리고, 저장된 파일이 칸별로 보이며, 눌러서 열린다(사진은 보이고 PDF는 열린다).
- AC4. 네트워크를 끊고 1일차에 항공권 제안 섬을 펼쳐 파일을 누르면 저장된 파일이 열린다. 입장권 제안 섬도 같다.
- AC5. 저장되지 않은 파일(스위치가 꺼진 여권)을 네트워크 없이 열려고 하면 "인터넷이 연결되면 열 수 있어요"가 보이고 오류 화면은 보이지 않는다.
- AC6. 파일을 지우면 기기의 저장분도 지워져서, 네트워크를 끊어도 다시 열리지 않는다.
- AC7. 로그아웃하면 기기에 저장된 서류가 모두 지워져서, 네트워크를 끊고 열어도 "오프라인 서류" 화면에 아무것도 보이지 않는다. 다른 계정으로 로그인해도 앞 계정의 파일은 보이지 않는다.
- AC8. 동반자 계정에서 함께 보기로 나눈 항공권 파일도 AC1과 같이 저장되고, 주인이 함께 보기를 끄거나 동반자가 여행에서 나가면 기기의 저장분이 지워진다(다음에 인터넷이 될 때).
- AC9. 인터넷이 약해 저장이 실패해도 서류 보관함의 다른 동작은 오류 없이 동작하고, 그 파일은 "오프라인 저장됨" 표시가 없다.

## 확정된 제약과 근거

- 기본 저장은 항공권, 입장권, 숙소 예약, 교통패스 칸의 파일이고, 여권, 여행자 보험, 직접 만든 칸의 파일은 사용자가 켠 것만 저장한다. 가장 급한 때가 항공권과 입장권을 보여 주는 순간이고 이 파일들은 노출돼도 피해가 작지만, 여권 사본이 기기에 남는 것은 위험하기 때문이다(사용자 확정, 2026-11-19).
- 로그아웃하면 기기에 저장된 서류를 모두 지운다. 공용 기기에 서류가 남지 않게 하기 위해서다(사용자 확정, 2026-11-19).
- 저장은 인터넷이 될 때 앱이 백그라운드로 하고, 사용자가 따로 누르지 않는다.
- 이 작업으로 [data-storage](../../decisions/data-storage.md)의 서류 파일 규칙에 "기기에 저장해 오프라인에서 열 수 있다"를 더하고, 오프라인 재검토 조건을 해소한 것으로 갱신한다.

## 가정 (바꿀 수 있음)

- 기기 저장은 브라우저의 저장소(서비스 워커와 브라우저 저장 공간)를 쓴다. 별도의 앱 설치는 필요 없다.
- 저장 총량은 기기당 50MB까지이고 넘으면 오래된 파일부터 저장하지 않고 "저장 공간이 부족해요"를 보여 준다.
- "오프라인 서류" 화면은 인터넷이 없을 때 앱 주소를 열면 자동으로 열리고, 인터넷이 되면 평소 화면으로 돌아간다.
- 오프라인 상태에서는 서류 열기만 한다. 올리기, 지우기, 칸 추가, 스위치 켜고 끄기는 인터넷이 필요하다고 안내한다.
- 저장된 파일이 서버에서 바뀌었는지는 인터넷이 될 때 확인한다(파일은 올린 뒤 바뀌지 않으므로 지워졌는지만 본다).
- 화면 시안은 만들지 않았다. 기존 서류 칸 카드에 표시와 스위치를 더하는 것이기 때문이다.

## 범위 밖과 이유

- 서류 외의 오프라인 사용(코스, 여비 기록, 체크리스트, 제안 섬) — 이번에는 서류 열기만 다룬다.
- 앱 설치(홈 화면 추가) 안내 — 별도 작업으로 다룬다.
- 오프라인 중 올린 파일이나 기록을 나중에 보내기(동기화) — 서류는 인터넷이 될 때만 올린다.
- 푸시 알림 — 이번 범위가 아니다.

## 미룬 결정

- 서류 외 오프라인 사용(코스 보기, 여비 기록): 서류 오프라인을 써 보고 필요하다고 할 때 정한다. 그때까지는 서류 열기만 된다(임시).

## 남은 위험

- 브라우저가 저장 공간이 부족하면 저장해 둔 파일을 임의로 지울 수 있고, 특히 iPhone의 Safari는 오래 쓰지 않은 사이트의 저장분을 지우기도 한다. 출발 직전 와이파이에서 앱을 한 번 열어 저장 상태를 확인하는 안내가 필요할 수 있다.
- 오프라인에서 PDF가 열리는 방식이 브라우저와 기기마다 달라, 휴대폰에서 안 열리는 경우가 있을 수 있다.
- 여권을 켠 사용자의 기기에는 서류가 남아 있어 기기를 잃어버리면 노출될 수 있다. 로그아웃 시 지우기로만 막는다.
- 앱 화면 자체를 오프라인에서 여는 구성은 로그인 상태와 겹쳐 복잡하다. 서류 화면 하나만 오프라인 대상으로 두어 범위를 줄였다.
