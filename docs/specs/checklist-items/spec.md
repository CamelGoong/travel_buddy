# 체크리스트 항목 추가·삭제: 내 여행에 맞게 챙길 것을 더하고 정리하기

출발 전 체크리스트에 직접 챙길 것을 더하고, 직접 더한 항목과 AI 제안으로 들어온 항목을 지울 수 있다. 기본 다섯 항목(여권, 항공권, 숙소 예약, 교통패스, 환전)은 지울 수 없다. [osaka-first-trip-loop](../osaka-first-trip-loop/spec.md), [trip-documents](../trip-documents/spec.md)가 다음 작업 단위로 미뤄 둔 "체크리스트 항목 추가와 삭제"를 해소한다.

연결된 근거:
- [PRODUCT.md](../../../PRODUCT.md) — 제품 전제. 이 작업에는 "출발 전에는 체크리스트로 준비를 챙긴다", "무겁지 않게, 필요한 순간에 필요한 것만"이 적용된다.
- [ui-composition](../../decisions/ui-composition.md) — 입력, 버튼, 확인 창, 빈 상태와 오류 상태는 공식 shadcn 구성을 쓴다. 화면 작업은 `DESIGN.md`부터 읽는다.
- [ai-course-draft](../ai-course-draft/spec.md) — AI 제안으로 체크리스트에 추가된 항목도 지울 수 있다.
- [trip-documents](../trip-documents/spec.md) — 기본 다섯 항목 중 여권, 항공권, 숙소 예약, 교통패스는 서류 파일을 올리면 자동으로 완료된다. 직접 더한 항목은 서류 칸과 연결하지 않는다.
- [trip-companions](../trip-companions/spec.md) — 항목 목록 변경은 주인만 하고, 완료 표시는 사람마다 따로 한다.
- [GLOSSARY.md](../../../GLOSSARY.md) — 체크리스트, 체크리스트 제안의 뜻.

## 사용자에게 보이는 결과

1. 체크리스트 아래에 "항목 추가" 입력이 있고, 이름을 적어 더하면 목록 맨 아래에 미완료로 들어간다.
2. 직접 더한 항목과 AI 제안으로 들어온 항목 옆에 지우기 버튼이 보이고, 누르면 확인을 한 번 거쳐 사라진다.
3. 기본 다섯 항목에는 지우기 버튼이 없다.
4. 지운 항목은 저녁 안내의 준비 항목에서도 빠진다.
5. 동반자 화면에는 항목 추가와 지우기가 보이지 않는다.

## 승인된 범위

- 직접 항목 추가(이름 1–20자)
- 직접 더한 항목과 AI 제안으로 들어온 항목의 삭제
- 기본 다섯 항목 보호
- 지운 항목의 준비 항목 반영

## 수용 기준

모두 실행 중인 앱에서 실제 브라우저로 확인한다.

- AC1. 항목 추가에 "휴대폰 충전기"를 적으면 체크리스트 맨 아래에 미완료로 들어가고 "n/6 완료" 같은 카운트에 반영된다. 새로고침하거나 다시 로그인해도 그대로다.
- AC2. 이름이 비어 있거나 20자를 넘으면 추가되지 않고 이유가 보인다. 이미 있는 항목과 이름이 같으면 추가되지 않고 이유가 보인다. 한 여행에 직접 더한 항목은 최대 20개이고, 넘으면 추가되지 않고 이유가 보인다.
- AC3. 직접 더한 항목과 AI 제안으로 들어온 항목에는 지우기가 있고, 누르면 확인 창이 뜬다. 취소하면 그대로이고, 확인하면 사라지며 새로고침해도 다시 보이지 않는다.
- AC4. 기본 다섯 항목에는 지우기 버튼이 없고, 지우는 요청을 직접 보내도 거절된다.
- AC5. 직접 더한 항목에 완료 표시를 하고 해제할 수 있다. 서류 보관함의 파일 올리기는 이 항목에 영향을 주지 않는다.
- AC6. 1일차 전날 저녁 안내의 준비 항목에는 직접 더한 미완료 항목이 기본 항목과 함께 보이고, 지운 항목은 보이지 않는다.
- AC7. 동반자 계정 화면에는 항목 추가 입력과 지우기가 보이지 않고, 같은 일을 하는 요청을 직접 보내도 거절된다. 완료 표시는 동반자도 각자 할 수 있다.

## 확정된 제약과 근거

- 기본 다섯 항목은 지울 수 없다. 서류 보관함의 자동 완료, 환율·교통패스 제안, 저녁 안내의 준비 항목이 이 항목들을 기준으로 동작하기 때문이다. 이미 챙긴 것은 완료 표시로 정리한다(사용자 확정, 2026-11-19).
- 직접 더한 항목과 AI 제안으로 들어온 항목은 지울 수 있다. 목록을 내 여행에 맞게 정리하기 위해서다(사용자 확정, 2026-11-19).
- 항목 추가와 삭제는 주인만 한다. 항목 목록은 여행의 모두에게 같고, 완료 표시만 사람마다 따로다([trip-companions](../trip-companions/spec.md)).

## 가정 (바꿀 수 있음)

- 직접 더한 항목은 서류 칸이나 제안과 연결되지 않는다.
- 항목 이름은 앞뒤 공백을 지우고, 같은 이름(대소문자 구분 없이)은 하나만 둔다.
- 기본 항목의 이름과 순서는 바꾸지 않는다. 직접 더한 항목끼리의 순서도 바꾸지 않고 더한 순서대로 둔다.
- 항목 이름 바꾸기는 없다. 틀리면 지우고 다시 더한다.
- 화면 시안은 만들지 않았다. 기존 체크리스트 카드에 입력 한 줄과 지우기 버튼을 더하는 것이기 때문이다.

## 범위 밖과 이유

- 기본 항목 삭제와 이름 바꾸기 — 다른 기능이 기본 항목을 기준으로 동작한다.
- 항목 순서 바꾸기, 항목별 메모와 기한 — 가벼운 체크리스트로 둔다.
- 직접 더한 항목에 서류 칸 연결 — 서류 보관함의 자동 완료는 기본 네 항목에 한한다.
- 항목 추가에 AI 제안 더 받기 — AI는 여행을 만들 때만 제안한다([llm-integration](../../decisions/llm-integration.md)).
