# 일차 동선 지도와 위치 검색, 여비 목록 줄이기

일차 화면의 코스 카드 오른쪽에 작은 동선 지도를 두고, 누르면 크게 펼쳐 구간별 이동 시간과 구글지도 길찾기로 이어지게 한다. 코스에 장소를 직접 입력해 더할 때는 이름으로 위치를 찾아 후보를 고르게 해서, 지도와 도착 알림이 함께 동작하게 한다. 이날 여비 카드는 건수와 합계를 머리에 두고 최근 세 건만 먼저 보여 준다. [trip-course-edit](../trip-course-edit/spec.md)이 미룬 "직접 입력한 장소에 좌표 붙이기"를 해소한다.

연결된 근거:
- [PRODUCT.md](../../../PRODUCT.md) — "처음 가는 길에서도 어려움 없이", "무겁지 않게, 필요한 순간에 필요한 것만". 이동은 구글지도 같은 외부 지도 앱의 길찾기로 넘긴다.
- [visual-theme](../../decisions/visual-theme.md) — 핀과 선은 앱의 보라에서 파랑으로 번지는 강조색을 쓰고, 지도를 여는 창은 유리 면을 따른다.
- [trip-course-edit](../trip-course-edit/spec.md) — 장소 추가와 순서·시각 편집. 위치 검색은 그 추가 흐름에 들어간다.
- [osaka-contextual-suggestions](../osaka-contextual-suggestions/spec.md) — 좌표가 있어야 도착 알림과 소요 시간 안내가 동작한다.
- [trip-companions](../trip-companions/spec.md) — 동반자도 동선 지도를 보고, 위치 검색과 편집은 주인만 한다.
- [ui-composition](../../decisions/ui-composition.md), `DESIGN.md` — 버튼과 목록 구성.
- [GLOSSARY.md](../../../GLOSSARY.md) — 일차, 코스 초안, 직접 입력 장소, 노선도의 뜻.

## 사용자에게 보이는 결과

1. 일차 화면의 코스 카드 오른쪽에 작은 정사각형 지도가 있다. 좌표가 있는 장소가 번호 핀(보라색)으로 찍히고 점선으로 이어져 순서와 방향이 한눈에 보인다. 장소에 좌표가 하나도 없는 일차에는 지도가 없다.
2. 작은 지도를 누르면 아래에서 큰 동선 지도가 펼쳐진다. 끌고 확대할 수 있고, 아래에 장소 목록과 구간별 "도보 약 3분", "대중교통 약 35분"이 보이고, "구글지도에서 길찾기" 버튼이 있다.
3. 편집 모드에서 "장소 추가"에 이름을 적고 "위치 찾기"를 누르면 오사카 근처 후보 몇 개가 주소와 함께 나오고, "여기로 추가"를 누른 후보의 위치로 장소가 더해진다. 못 찾거나 원하지 않으면 "위치 없이 이름만 추가"로 더할 수 있다.
4. "이날 여비" 머리에 합계와 건수가 보이고, 목록에는 최근 세 건만 보인다. 네 건 이상이면 "N건 더 보기"로 펼치고 "접기"로 접는다. 필터 칩은 네 건 이상일 때만 보인다.

## 승인된 범위

- 일차 코스 카드의 작은 지도, 누르면 펼쳐지는 큰 동선 지도, 구간별 이동 시간, 구글지도 길찾기 링크
- 장소 추가 시 이름으로 위치 찾기(후보 고르기)와 위치 없이 추가하기
- 이날 여비 목록의 건수 표시, 최근 세 건과 더 보기, 필터 칩 노출 조건

## 수용 기준

실행 중인 앱에서 실제 브라우저로 확인한다. 지도 이미지는 인터넷이 필요하다.

- AC1. 좌표가 있는 장소가 둘 이상인 일차에 작은 지도가 보이고, 번호 핀이 목록의 번호와 같은 순서로 찍히며 점선이 순서대로 이어진다. 좌표 없는 장소는 핀 없이 목록에만 있다. 장소가 하나면 핀만 보이고 점선은 없다. 좌표가 있는 장소가 없으면 지도가 없다.
- AC2. 작은 지도는 끌거나 확대되지 않고 누르기만 된다. 누르면 큰 지도 창이 열리고, 같은 핀과 선, 끌기와 확대, 장소별 시각, 구간별 이동 시간이 보인다. 닫기 버튼과 Esc로 닫힌다. 지도 이미지 출처(OpenStreetMap)가 큰 지도에 보인다.
- AC3. 큰 지도의 "구글지도에서 길찾기"를 누르면 첫 장소에서 시작해 마지막 장소로 가는, 중간 장소를 거치는 구글지도 길찾기가 새 탭으로 열린다. 좌표 있는 장소가 둘 미만이면 이 버튼이 없다.
- AC4. 편집 모드에서 "이치란 도톤보리점"을 적고 "위치 찾기"를 누르면 오사카 근처 후보가 주소와 함께 나온다. 후보를 골라 추가하면 그 장소가 이름과 위치와 함께 더해지고, 작은 지도에 핀이 생긴다. 후보에 오사카와 근교 밖의 곳은 나오지 않는다.
- AC5. 찾는 중에는 진행 중임이 보이고, 결과가 없거나 검색이 실패하면 안내가 보이며 "위치 없이 이름만 추가"로 계속할 수 있다. 오류 화면은 보이지 않는다.
- AC6. 동반자 계정 화면에는 편집과 위치 찾기가 보이지 않고, 같은 일을 하는 요청을 직접 보내도 거절된다. 동선 지도는 보인다.
- AC7. 이날 여비 머리에 "합계 N엔 · n건"이 보인다. 세 건 이하이면 모두 보이고 "더 보기"가 없다. 네 건 이상이면 최근 세 건만 보이고 "N건 더 보기"가 있으며, 누르면 모두 보이고 "접기"로 되돌아간다.
- AC8. 여비가 세 건 이하이면 필터 칩이 보이지 않고, 네 건 이상이면 보인다. 필터를 걸었을 때 걸러진 합계와 건수는 이전과 같이 보인다.

## 확정된 제약과 근거

- 지도는 무료 지도 이미지(OpenStreetMap)에 앱의 보라색 핀과 점선을 올리는 방식이다. 구글지도는 API 키와 결제 수단이 필요해서 쓰지 않는다(사용자 확정, 2026-11-19).
- 동선은 대략적인 위치와 방향만 보이게 간단히 한다. 구체적인 확인은 눌러서 펼친 큰 지도에서 한다(사용자 확정, 2026-11-19).
- 길찾기는 구글지도로 넘긴다. 키 없이 열리는 구글지도 주소만 쓴다.
- 이날 여비 목록은 합계와 건수를 머리에 두고 최근 세 건만 먼저 보여 준다. 전부 보이면 카드가 길어지고, 머리 요약만 두면 방금 적은 것을 확인하려 매번 펼쳐야 하기 때문이다(사용자와 함께 정함, 2026-11-19).
- 위치 검색은 오사카와 당일치기 근교 안에서만 받는다.

## 가정 (바꿀 수 있음)

- 위치 찾기는 OpenStreetMap의 Nominatim 검색을 서버에서 부른다. 키가 필요 없고 사용 정책의 낮은 호출량 기준을 따른다. 결과는 하루 동안 저장해 같은 검색을 다시 부르지 않는다.
- 일본 가게 이름은 구글만큼 잘 찾지 못할 수 있어서 후보를 최대 여섯 개 보여 주고 고르게 한다.
- 장소에 저장되는 이름은 사용자가 적은 이름이고, 위치만 고른 후보에서 가져온다.
- 구간 이동 시간은 직선 거리로 어림한 값이다(1km 이하는 도보, 그 이상은 대중교통). 실제 시간은 길찾기에서 본다.
- 지도 이미지는 OpenStreetMap 표준 타일을 쓴다. 이 서비스의 호출량이 작은 동안만 정책에 맞다.
- 이미 위치 없이 더한 장소는 그대로 두고, 다시 위치를 붙이는 기능은 이번에 만들지 않는다.
- 화면 시안은 세 가지 안(간단 그림, 무료 지도, 구글지도)을 비교해 무료 지도 안을 골랐고, 시안 파일은 버렸다.

## 범위 밖과 이유

- 구글 장소 검색과 구글지도 보기 — 키와 결제 수단 등록이 필요하다.
- 걸어서·지하철 실제 경로선과 정확한 이동 시간 — 길찾기 앱이 더 정확하다.
- 현재 위치를 지도에 표시하기 — 위치 권한을 지도에 쓰지 않는다.
- 여행 전체 동선 지도(여러 일차를 한 지도에) — 일차 단위로만 보여 준다.
- 지도 오프라인 저장 — 오프라인은 서류만 다룬다.
- 이미 더한 위치 없는 장소에 위치 붙이기 — 지우고 다시 더하면 된다.

## 미룬 결정

- 지도 타일 서비스 바꾸기(유료 또는 다른 무료 타일): 사용자가 늘어 OpenStreetMap 정책의 호출량을 넘길 수 있을 때 다시 정한다. 그때까지는 표준 타일을 쓴다(임시).

## 남은 위험

- OpenStreetMap 타일 서버는 호출이 많아지면 차단될 수 있다. 막히면 지도가 비어 보이고 핀과 점선만 남는다.
- Nominatim이 일본 가게 이름을 잘 못 찾을 수 있다. 위치 없이 이름만 추가하는 길을 열어 둔다.
- 작은 지도 안의 지도 이미지는 인터넷이 약하면 늦게 뜬다.
- 이동 시간이 직선 거리 기준이라 실제와 크게 다를 수 있다. 큰 지도에 안내 문구를 둔다.
