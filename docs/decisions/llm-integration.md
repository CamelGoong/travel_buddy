# LLM 연동

## Decisions

- LLM은 두 곳에만 쓴다. 여행을 만들 때의 **코스 초안**과, 출발 전 **체크리스트**에 더할 추가 항목 제안이다. 체크리스트 기본 다섯 항목(여권, 항공권, 숙소 예약, 교통패스, 환전)은 그대로 두고, LLM은 동반자·기간·코스에 맞는 항목을 "이거 필요해?" 형태로 더 제안만 한다.
- 아침 안내, 저녁 안내, 옷차림 한 줄, 준비 항목, 환전 시점 안내에는 LLM을 쓰지 않는다. 날씨·환율 API 수치와 정해 둔 규칙·문구로 만든다.
- 공급자는 Google Gemini API의 무료 등급으로 시작한다. 모델은 적당한 성능의 가벼운 Flash 계열(Flash-Lite급)을 쓴다. 정확한 모델 ID는 코드에 박지 않고 서버 환경 변수 `GEMINI_MODEL`로 두고, 구현할 때 공식 모델 목록에서 최신 안정 ID를 골라 정한다.
- 호출은 서버에서만 한다. 공급자 호출 코드는 서버 전용 파일 하나에 모으고, 여행 만들기 Server Action(`app/trip/new/actions.ts`)이 그 파일을 부른다. 브라우저에서 부르는 Route Handler는 만들지 않는다.
- API 키는 서버 환경 변수 `GEMINI_API_KEY`에만 둔다. 로컬은 `.env.local`, 배포는 Vercel 환경 변수에 넣는다. `NEXT_PUBLIC_` 접두사를 붙이지 않는다.
- 응답은 정해 둔 JSON 형태(일차별 장소 이름과 예정 시각, 추가 체크리스트 항목)로 받고, 서버에서 형태를 검사한 뒤 저장한다.
- 결과는 여행을 만들 때 한 번 생성해 기존 코스 초안·체크리스트 테이블에 저장한다. 화면을 열 때는 LLM을 다시 부르지 않는다. 별도 캐시 테이블은 두지 않는다.
- 호출이 실패하면 고정 목록으로 조용히 대체한다. 오류, 제한 시간 초과(기본 10초), 무료 한도 초과(429), 형태 검사 실패가 모두 해당한다. 대체 목록은 지금의 오사카 명소 목록과 기본 다섯 항목이다. 여행 만들기 자체는 LLM 때문에 실패하지 않는다. 대체되었을 때는 코스 초안에 "기본 코스"임을 작게 표시한다.
- 비용 상한: 결제 수단을 연결하지 않은 무료 등급만 쓰므로 요금은 0원이다. 앱에서도 사용자당 하루 AI 생성 5회와 호출당 출력 토큰 상한을 두고, 넘으면 고정 목록을 쓴다.

## Boundaries

- LLM 결과는 제안일 뿐이다. 코스와 추가 체크리스트 항목은 사용자가 보고 확인하며, 구매나 예약을 실행하지 않는다. 구매는 기존 경계대로 마이리얼트립 검색 결과로 넘긴다.
- 이 결정은 코스를 "다시 짜 줘" 하는 재생성, 대화형 기능, 여행 중 실시간 제안에 LLM을 쓰는 것을 허용하지 않는다. 필요해지면 비용과 함께 다시 정한다.
- 대상 도시를 늘리는 일은 이 결정의 범위가 아니다. 대체용 고정 목록이 있는 도시(지금은 오사카)에서만 AI 코스를 켠다.

## Why

사용자는 아직 유료로 쓰는 LLM이 없고, "적당한 성능에 끊기지 않고 오래 쓰는 것"을 원했다. 강사가 추천한 "Luna"는 OpenAI `gpt-6-luna`로 확인되었다. 싸지만 최소 $5를 선충전해야 하고, 신규 무료 크레딧은 없다. Gemini Flash 계열은 카드 없이 무료 등급으로 바로 쓸 수 있어서, 시작 비용이 없는 쪽을 골랐다. 무료 한도가 작다는 약점은 여행을 만들 때 한 번만 부르는 구조와 고정 목록 대체로 메운다. 그러면 한도에 걸려도 사용자 흐름이 끊기지 않는다.

LLM이 실제로 차이를 만드는 곳은 기간·동반자·취향에 맞춘 명소 순서와 시간 배치처럼 규칙으로 만들기 어려운 일이다. 안내 문구와 환전 안내는 규칙과 API로 충분하다. 매일 부르면 비용과 지연만 늘고, 환율을 LLM이 풀어 말하면 투자 조언처럼 들릴 위험이 있다.

## Reconsider when

- 무료 한도(429) 때문에 고정 목록 대체가 자주 일어난다는 근거가 나올 때. 이때는 `gpt-6-luna`에 $5를 선충전하고 자동 충전을 꺼서 상한을 고정하는 쪽으로 옮긴다. 호출 파일 하나와 환경 변수만 바뀐다.
- 실제 사용자가 생기거나 상업적으로 운영할 때. 무료 등급의 입력은 Google이 제품 개선에 쓰고 사람이 볼 수 있으므로, 그때는 유료 등급이나 다른 공급자로 옮긴다.
- Flash-Lite급 코스 품질이 낮다는 근거가 나올 때(없는 장소, 동선이 엉뚱한 순서). 한 단계 큰 Flash 모델을 먼저 시도한다.

## Still-rejected alternatives

- OpenAI `gpt-6-luna`로 바로 시작 — 품질과 가격은 충분하지만 최소 $5 선충전이 필요하다. 무료 한도가 실제로 부족해지면 다시 검토한다.
- Vercel AI Gateway(월 $5 무료 크레딧) — 키 하나로 모델을 바꾸기 쉽지만 무료 크레딧으로 쓸 수 있는 모델이 일부로 제한되고, 크레딧을 한 번 사면 무료분이 끝나며, 자기 키 연결에도 크레딧 구매가 필요하다는 자료가 있다. 여러 공급자를 오가야 할 때 다시 검토한다.
- Claude Haiku 5.5 — `gpt-6-luna`와 같은 가격이지만 무료 등급이 없다. 유료로 옮길 때 후보로 함께 비교한다.
- 아침/저녁 안내 문구와 환전 안내에 LLM 사용 — 매일 부르는 비용에 비해 얻는 게 적고, 환전 안내는 투자 조언처럼 들릴 수 있다. 규칙 문구가 촌스럽다는 근거가 나오면 문구 다듬기만 다시 검토한다.

## Evidence worth preserving

- 2026-11-19 공식 가격 페이지 기준(100만 토큰당): `gpt-6-luna` 입력 $0.10·캐시 입력 $0.01·출력 $0.50, `gpt-5.6-luna` $0.20·$0.02·$1.20, Claude Haiku 5.5(`claude-haiku-5-5`, 10만 토큰 이하) 입력 $0.10·출력 $0.50.
- 코스 초안 한 번에 입력·출력 각 2천 토큰 정도로 잡으면 `gpt-6-luna` 기준 약 $0.0012이고, $5로 약 4천 번 부를 수 있다.
- Gemini 무료 등급 한도는 Google이 고정 표로 공개하지 않고 프로젝트별로 AI Studio에서 보여 준다. 제3자 자료의 Flash 무료 한도는 하루 20–1,500회로 엇갈린다.
